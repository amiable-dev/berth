## Responsibilities

- Review and merge pull requests; keep CI green on Ubuntu and macOS
- Triage issues within the response times in [SUPPORT.md](SUPPORT.md)
- Accept, supersede and number ADRs in `docs/adr/`
- Cut releases per [CONTRIBUTING.md](CONTRIBUTING.md#releasing-maintainers) and keep `CHANGELOG.md` accurate
- Handle security reports per [SECURITY.md](SECURITY.md)
- Enforce the [Code of Conduct](CODE_OF_CONDUCT.md)
- Keep the published package at zero runtime dependencies and every workflow least-privilege

## Becoming a Maintainer

Sustained, quality contributions over several months, nomination by an existing maintainer, and approval by the existing maintainers. New maintainers are added to the table above in the same PR that grants access.
