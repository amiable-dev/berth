design pack · v0.1 · 2026-09-13

berth ui

Instrument-panel language for an advisory port registry. Monospace everywhere, hairline rules, near-black ground, phosphor state colours. Information, not gates: the UI names holders and suggests commands; it never kills, blocks or reassigns.

→ prototype: Berth Dashboardsource: docs/DESIGN.md §5.4, §5.8

01 · principles

The number is the rule
Every port is decodable: 10000 + 1000·P + 100·W + R. The UI always shows the decode, never asks the user to look it up.
Dense by default
Thirty sessions × fifty ports must fit one screen beside a terminal. 12px body, 22px rows, no card padding.
Colour means state, nothing else
Eight state hues and one link blue. Brand is type and rhythm, not colour. Hatching doubles the signal for the four states that need a human.
Always say how we know
Every state is backed by its evidence: claim file, lsof, compose label, ps -E marker. Attribution is the product.

03 · state system · eight states

chipdarklightmeaningadvisory responsemap cell
{{ s.name }} {{ s.dark }} {{ s.light }} {{ s.meaning }} {{ s.response }} {{ s.cellNote }}
Traffic-light logic. Green = as agreed. Amber family = leased but not right (idle, stale, orphan), darker and more orange as the owner gets further from alive. Red family = another party is involved (squatter, conflict). Blue = configuration, not runtime (drift). Grey = nobody asked (unmanaged).
Chip anatomy. 10px, uppercase, .06em tracking, 1px border in the state colour, no fill. Text is the state word exactly as berth check prints it, so terminal and UI vocabulary are identical.
Idle is dimmed, not coloured. Rows at 55% opacity; the chip stays legible. Idle is the one state that should recede.

columnstwo-space indent, left-aligned labels padded to 9 chars, values start at column 12. Same widths in ls, who, check. colouronly the state word is coloured, using the same eight ANSI-nearest hues. Honour NO_COLOR; never colour numbers or paths. evidence"because" lines repeat the word rather than numbering, so grep works and the human reads them as a chain. exitevery command prints its exit code in the summary line; it is always 0, and saying so is the point. json--json emits exactly the object the dashboard renders. Field names are the lease schema in DESIGN.md §5.3.

08 · copy and tone

Name the holder, never the villain
"node 8812 (vite) · session 38c7f0de" not "rogue process". Squatter and conflict are states, not accusations; the sentence always says who and how we know.
Suggest, do not instruct
"Suggest release" / "offer adopt". One command per advisory, copyable, with the port filled in. No "you should", no exclamation marks.
Lower-case vocabulary from the CLI
ok, idle, stale, orphan, unmanaged, squatter, conflict, drift — exactly as berth check prints them. Chips uppercase them visually via CSS only.
Say how we know
Evidence is named by mechanism: "compose label", "ps -E", "claim file", "netstat". Never "detected" or "we think".
Numbers stay raw
Ports, pids and ranges are never formatted with separators. Ages are "0h 31m", "2d 4h". Times are 24h local.
Empty states are sentences
"No leases match the current filters." / "Nothing bound; owner pid 5588 alive." Full stop, no icon, --dim.
